App Manager Tech is a fully local Android app manager and cleaner. Inspect every installed app, act on several at once, clean caches and see what each app can reach — without a single byte leaving your device.

<b>Features</b>

• Installed apps — sizes, last use, install source (Play / F-Droid / Aurora / sideloaded), category; search, sort, filters, your own tags
• Batch actions — uninstall, clear cache, force stop. Android confirms each app itself; App Manager Tech never bypasses it
• App detail — storage, permissions, a plain-language summary, privacy score, trackers, signing certificate, expert view of components
• Trackers — detects known advertising, analytics and crash-reporting SDKs, offline
• Privacy score — a 0–100 estimate from dangerous permissions, overlay, device admin, accessibility and install source
• Smart cleaner — one ranked list: unused apps, large caches, large rarely used apps, several apps of the same kind
• Storage analyser, rarely used apps, zombie apps, filter by permission
• Security audit — device administrators and enabled accessibility services
• Permission changes — what each app was granted or lost between snapshots (opt-in)
• Install history — installs, updates and uninstalls (opt-in)
• Signature clusters — apps grouped by signing certificate
• Quarantine — set an app aside with a review date: a reminder, or an uninstall after backing up its APK to a folder you choose
• Trash — stage uninstalls and review them first
• Protected apps — a 3-second hold before destructive actions, on your apps and on built-in lists: authenticators, password managers, encrypted messengers, health, French banks and transport
• Action journal — a local record of what App Manager Tech did (opt-in)
• Export — JSON, CSV, and a printable PDF diagnostic
• Background scan — one local notification when the total cache crosses your threshold
• Screenshot blocking (opt-in), Material You, light / dark theme
• English, French, German, Italian, Spanish

<b>Privacy</b>

• No INTERNET permission — the app cannot open a network connection
• No analytics, no crash reporter, no tracking SDK
• Apache License 2.0 — https://github.com/gitubpatrice/APP-MANAGER-TECH

<b>Permissions</b>

QUERY_ALL_PACKAGES — list installed apps
PACKAGE_USAGE_STATS — last use and exact sizes (granted in Android Settings; without it, sizes show 0 and apps “Never used”)
GET_PACKAGE_SIZE — app sizes
REQUEST_DELETE_PACKAGES — open Android's uninstall dialog (you confirm)
REQUEST_INSTALL_PACKAGES — restore a quarantined app from its backed-up APK (Android asks you to allow it, then to confirm)
KILL_BACKGROUND_PROCESSES — stop background processes
POST_NOTIFICATIONS (Android 13+) — local notifications
WAKE_LOCK, FOREGROUND_SERVICE, RECEIVE_BOOT_COMPLETED, ACCESS_NETWORK_STATE — added by WorkManager for background jobs. ACCESS_NETWORK_STATE tells whether a network exists; without INTERNET the app cannot use it
